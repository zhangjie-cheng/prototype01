# 幻馨 AI 商家端交互原型

根据 Axhub 参考原型重新实现的独立前端项目。项目不连接后端，所有数据和交互均为演示用途。

## 页面

- 登录与注册
- 用户协议、隐私政策
- 商家首页、安全说明、账户余额
- 企业通讯录与组织架构管理
- 角色管理与权限配置
- 对话页、对话结果页
- 静态知识库、静态知识库文件列表
- 动态知识库、动态知识库文件列表

## 已实现交互

- Hash 路由和侧边栏页面导航
- 登录/注册切换、验证码倒计时、协议跳转
- 新建知识库、上传文件、新建动态信源、充值弹窗
- 知识库和文件搜索、列表勾选、全选、状态开关
- 余额消费/充值明细切换
- 智能体选择、发送问题并进入对话结果页
- 用户头像菜单、关于弹窗、企业通讯录搜索和部门筛选
- 角色增删改查、启停状态、操作权限和数据访问权限设置
- 桌面端与移动端自适应布局

## 运行

现在可以直接双击 `index.html` 使用，无需启动服务器。

也可以使用本地静态服务器启动：

```bash
cd outputs/huanxin-ai-prototype
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/#/login`。

如果本机已安装 Node.js，也可以使用：

```bash
npm install
npm run dev
```
